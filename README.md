# homebrew-fatou (deprecated)

> [!IMPORTANT]
> This tap is retired. `fatou` now lives in
> [**jolars/homebrew-tap**](https://github.com/jolars/homebrew-tap) alongside
> the other jolars tools.

Install from the new tap:

```sh
brew install jolars/tap/fatou
```

If you installed `fatou` from this tap, no action is needed: `tap_migrations.json`
here redirects Homebrew to `jolars/tap`, so `brew update` migrates you
automatically.
